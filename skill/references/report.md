# 任务报告

一轮任务结束后附报告：结论、要点、口径与证据，下载得到可分享的独立网页

- 栅栏：```report
- 引擎：内置于插件（无第三方引擎，投影在本地计算）
- 字体：字体使用宿主应用的字体栈，与正文同字号（13px），无需你处理。

## 语法

JSON：{ "title": "…", "round": "第 43 轮 · 2026-10-20", "status": "done|partial|blocked|failed", "verdict": "一两句说清交付了什么", "facts": ["要点"], "meta": { "基线": "…" }, "notes": ["提示"], "sections": [{ "title": "用户能感知到的变化", "items": ["…"] }] }；下载得到的是完整网页

## 易错点

- JSON：{ "title": "…", "round": "第 43 轮 · 2026-10-20", "status": "done|partial|blocked|failed", "verdict": "一两句说清交付了什么", "facts": ["要点"], "meta": { "基线": "…" }, "notes": ["提示"], "sections": [{ "title": "用户能感知到的变化", "items": ["…"] }] }；下载得到的是完整网页
