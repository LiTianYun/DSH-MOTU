# nomnoml

极简框线图 —— 语法最短，适合小而清楚的流程

- 栅栏：```nomnoml
- 引擎：graphre@0.1.3, nomnoml@1.7.0
- 字体：该引擎只能指定**单一字体族**（CSS 字体栈无效）。中文必须显式写字体，否则标签会缺字。

## 语法

[A] -> [B]；边标签写在端点和箭头之间：[A] 是 -> [B]；决策就是普通方框 [命中]，不要写 <choice>（尖括号会被当文本渲染）；中文必须加 #padding: 22 补偿它按西文字宽估算

## 完整示例

```nomnoml
#padding: 22
#fill: #f7f8fb
#stroke: #8a94a6
[开始] -> [读取数据]
[读取数据] -> [校验通过]
[校验通过] 是 -> [写入结果]
[校验通过] 否 -> [记录错误]
[写入结果] -> [结束]
[记录错误] -> [结束]
```
